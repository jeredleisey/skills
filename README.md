# skills

A marketplace of Claude Code plugins, named `jeredleisey`.

## Plugins

- `cadre`: run a team of agents on a software repo. An orchestrator shapes the work, gives tickets to helpers in role cards, and verifies what they return.

## Install

```
/plugin marketplace add jeredleisey/skills
/plugin install cadre@jeredleisey
```

## Checks

```
node --test
node tools/check.mjs
```
